# iM 리스크 코치 데모

iM Agentic Coding Challenge 2026 참가용으로 제작한 정적 웹 기반 PoC입니다.

## 프로젝트 개요
- 주제: **iM 리스크 코치 : 연체 사전예방 알림 및 상환지원 서비스**
- 목적: 대출 상환일, 자동이체 일정, 최근 거래 패턴을 기반으로 연체 가능 고객을 사전 탐지하고, 고객 알림과 직원 모니터링 화면을 통해 행동을 유도하는 데모 제공
- 데이터: **가상/샘플 데이터만 사용**

## 포함 화면
1. 서비스 개요
2. 고객 알림 화면
3. 직원 대시보드
4. 성과 시뮬레이션

## 실행 방법
별도 빌드 없이 바로 실행 가능합니다.

### 방법 1. 로컬에서 바로 열기
`index.html` 파일을 브라우저에서 열면 됩니다.

### 방법 2. 간단한 로컬 서버 실행
Python 3가 설치되어 있다면 아래 명령으로 실행할 수 있습니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속

## GitHub Pages 배포 방법
1. 이 폴더 전체를 GitHub 저장소에 업로드
2. 저장소의 **Settings > Pages** 이동
3. **Deploy from a branch** 선택
4. Branch를 `main`, 폴더를 `/root`로 선택
5. 저장 후 몇 분 뒤 배포 완료
